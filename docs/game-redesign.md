# 3ゲーム詳細設計(2026-07-28決定分)

見た目の刷新(コミット `d0b9930`)の後、以下の詳細設計指示を受けた。実装未着手のまま
アイディア出しスレッド側は中断し、VSCode側で実装を引き継ぐ。

## ① 宝くじ確率いいかえ

- 冒頭で **モード選択画面** を表示してから問題を開始する(現状は問題画面内のチップで
  いつでも切り替えられる方式だったが、開始前の選択に変更)。選択肢: 一般編 / ギャンブラー編 /
  ミックス(両モードの問題が混ざる)
- **5問1セット**。1問ごとに進捗を表示し、5問終わったら結果画面(既存の共通結果画面)へ
- 現状は正解・不正解に関わらず常に内訳(breakdown)と倍率を表示していたが、変更後は:
  - **不正解時**は内訳を即表示せず、「もう一度挑戦」と「回答を見る」の2択を出す
    - もう一度挑戦: 同じ問題(同じtarget/components)のまま選択をリセットして再挑戦
    - 回答を見る: 選択肢それぞれの確率を表示してから次の問題へ進む
  - **正解時**は現状通り内訳と倍率を表示して次の問題へ
- 確率表記は分数だけでなく **日本語の位取り表記** を併記する(例: `1/100000000` だけでなく
  「(1億分の1)」のように)。既存の`formatOdds`に位取り変換を追加する

## ② 前髪のびたかゲーム(全面刷新)

- 現状: 「前髪を5秒で覚えてください」→タイマー→「伸びてる?変わってない?」の二択
- 変更後: **デートの待ち合わせで女性が来るシチュエーション**
  - 女性が来て数秒表示
  - 画面が切り替わる(=間違い探しの構図)
  - 「どこが変わった?」という質問
  - 選択肢は服の色・靴の色など **複数属性の変化点** + **固定で1番目の選択肢に「前髪切った」**
  - 「前髪切った」が正解のときとダミーのとき両方あってよいが、選択肢の並び順は
    「前髪切った」が常に一番上
- 旧来の「5秋で記憶→タイマー」の緊張演出はなくなり、間違い探し形式(2枚の絵を比較して
  どこが変わったかを当てる)に変わる

## ③ ことわざクイズ(全面刷新)

- 現状: ことわざが先にあり、シチュエーションを見てどのことわざかを当てる4択クイズ
- 変更後: **順序が逆転**する
  - 生活シチュエーションが提示され、「あなたならどうする?」という行動の複数選択が出る
  - 選択肢は演出付き(例: 「卵を一気に運ぶ」「分けて運ぶ」「人に運ばせる」など、行動の見た目が
    アニメーションで見える)
  - 正解を選ぶと、その根拠となることわざが明かされる
  - ことわざは **海外(主にアメリカ)のことわざ** を使う。例: "Don't put all your eggs in
    one basket"(卵を一つのかごに盛るな→リスク分散をしよう)
  - 日本人の感覚から離れている(意外性がある)ものほど「くすっと」感が強く、狙い目

## 実装順序の目安

宝くじ(既存の拡張で済む)→前髪→ことわざ の順。前髪とことわざは実質的に作り直し。
